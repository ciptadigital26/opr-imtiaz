Saya akan pindahkan kedua-dua fungsi backend (Telegram dan AI) ke **Vercel API Routes** (`/api/...`). Supabase dikekalkan hanya untuk log masuk, pangkalan data dan storan gambar, kerana Vercel tak ada sistem log masuk dan pangkalan data sendiri. Sekarang saya uji kedua-dua API dalam Node, dengan Telegram, Supabase dan Anthropic disimulasikan. API lulus semua ujian. Sekarang saya uji aplikasi penuh dalam pelayar, menghubungi `/api/...`. Semua lulus. Sekarang saya tulis semula README dan bungkus projek. Backend Telegram dan AI kini berjalan sebagai **Vercel API Routes** dalam projek yang sama. Tak perlu lagi Supabase CLI atau Edge Functions. **Struktur baharu (`opr-idexs-generator-vercel.zip`):** - `index.html`: aplikasi. Ia kini panggil `/api/telegram-send` dan `/api/ai-extract` pada domain yang sama. - `api/telegram-send.js` menghantar OPR ke group. Sebelum hantar, ia semak pengguna dah log masuk dan OPR dah CONFIRMED. Ia juga sediakan butang Uji sambungan untuk admin. - `api/ai-extract.js`: AI OCR dan jana impak menggunakan Claude API. - `package.json` dan `vercel.json`: tiada pakej tambahan perlu dipasang. **Rahsia kini disimpan di Vercel:** Settings → Environment Variables: - `TELEGRAM_BOT_TOKEN` - `TELEGRAM_CHAT_ID` - `ANTHROPIC_API_KEY` - `SUPABASE_URL` - `SUPABASE_ANON_KEY` Semuanya ditaip terus di dashboard Vercel, tanpa command line. **Supabase masih diperlukan** untuk log masuk guru, pangkalan data OPR dan storan gambar, kerana Vercel tiada sistem log masuk dan pangkalan data sendiri. Anda hanya perlu jalankan `schema.sql` sekali sahaja. **Had saiz Vercel (4.5 MB):** aplikasi akan mengecilkan gambar sebelum dihantar ke AI. OPR dihantar ke Telegram sebagai JPG atau PDF, manakala muat turun PNG masih boleh dibuat seperti biasa. **Ujian:** - Kedua-dua API diuji dalam Node.js dengan Telegram, Supabase dan Anthropic disimulasikan. Semua kes lulus: hantar berjaya, belum CONFIRM, bukan admin, token salah, ralat Telegram dan tiada Environment Variable. - Aliran penuh dalam pelayar juga lulus tanpa ralat. - Saya tak dapat uji dengan Vercel, Telegram dan Anthropic yang sebenar dari sini. Selepas deploy, buka `https://.vercel.app/api/telegram-send` untuk pastikan ia papar `"configured":true`, kemudian tekan **Uji sambungan Telegram** dalam Tetapan.
